Wire the incoming phone call.

  1. Create the OpenAI webhookIn the OpenAI project used by your API key, add the incoming Realtime call event and the webhook below. Save the signing secret in Railway.
  2. Point the SIP trunk at the same projectCopy the project ID from OpenAI project settings, then use the destination builder below. Select TLS/SRTP in your phone provider.
  3. Authorise the phone routeAttach a staging number to the trunk. Meridian’s private deployment controls must map that number to the correct approved agent.
  4. Prove the callCall the number. Confirm natural audio, interruption, outcome logging, human fallback and each advertised tool. Record client acceptance before activation.

The ID starts with proj_. Keep your secret API key out of this field.

Connect calendar truth.

The booking agent needs a verified calendar adapter. The importable n8n bridge validates Meridian requests and calls your configured HTTPS adapter. It is not a Google Calendar account connection by itself.

Before enabling booking: verify availability, create a test event, reschedule it, cancel it, and confirm failures never produce a spoken success. No calendar access or evidence is published here.

Customer launch has an acceptance gate.

Provider configuration is not a completed deployment. Meridian’s private controls verify connectors, the inbound route, staging evidence, rollback ownership and client approval. The public status check exposes no client records, phone numbers or secrets.
