Security posture

How Meridian protects customer agents, keys, and conversations. Built for Ontario SMBs with PIPEDA-minded defaults — not theater.

Keys & surfaces
  • Secret API keys (mdn_) stay on servers, n8n, and phone platforms — never in website HTML.
  • Public widget tokens (mdnw_) are chat-only, rate-limited, and separate from secret keys.
  • Provider keys (Anthropic, xAI, Stripe, Resend, Twilio) live only in Meridian server environment variables.
  • Key comparison uses timing-safe checks; agent records store hashes, not raw secrets.
Abuse & network
  • Helmet security headers and Content-Security-Policy on every response.
  • Rate limits on public chat, widget, voice previews, and funnel endpoints.
  • Widget spam soft-filter for obvious SEO/lead spam patterns.
  • Website knowledge scrape blocks private/local network hosts (SSRF guard).
Payments
  • Stripe Checkout + signed webhooks — Meridian never stores full card numbers.
  • Hosted xAI voice is balance-checked before provider calls and charged only after success.
Agent containment + expert gate
  • OpenClaw autonomous install is contained: config packs, transactional email, drafts — not bank logins, customer inboxes, or arbitrary file access.
  • Expert gate: every OpenClaw agent loads its training .md from disk before every task (fail closed if missing).
  • Public report: /api/openclaw/containment · /api/openclaw/experts
Truth & reliability
  • Agents are bound to business facts + knowledge base with anti-hallucination rules.
  • If Claude is slow or down, a deterministic fallback still answers hours/booking intents — no silent failure.
  • Phone default path uses platform TTS so calls keep working if Meridian-hosted audio is unavailable.
  • Emergency / human-request intents alert the business owner when notify contacts are set.
Data & privacy
  • We minimize what we store: agent config, interaction logs for your dashboard, billing balances.
  • No selling of lead lists. Marketing email requires consent (CASL-aligned).
  • See Privacy Policy and Terms for full legal language.
  • Enterprise SOC 2 / HIPAA BAA are not claimed until formally attested — we do not invent compliance badges.

Subprocessors (typical)

  • Railway — application hosting
  • Stripe — payments
  • Anthropic — LLM brain (when configured)
  • xAI — optional hosted TTS
  • Resend — transactional email
  • Twilio — optional SMS (only if you enable)
  • Retell / Vapi / Bland — customer-chosen phone platforms

Exact stack depends on which features you enable for your agent.
