3. Website widget — fastest install

Best for: “I just need the agent answering visitors on my site.” No developer required for most builders.

Steps

  1. Open your personal connect guide and copy the widget snippet.
  2. Paste it before </body> on every page you want the chat (or site-wide footer).
  3. Hard-refresh the site. You should see a bubble bottom-right.
  4. Send: “What are your hours?” — reply must match your business facts.
Snippet shape (your guide fills real values)
<script
  src="https://meridian-production-2eb0.up.railway.app/widget.js"
  data-agent="agent_YOUR_ID"
  data-token="mdnw_YOUR_PUBLIC_TOKEN"
  data-name="Your Business Name"></script>

Where to paste

  • WordPress — Appearance → Theme File Editor → footer.php, or a “Custom HTML” block in the footer template / plugin like Insert Headers and Footers.
  • Shopify — Online Store → Themes → Edit code → theme.liquid before </body>.
  • Squarespace / Wix — Settings → Custom code / Embed → site footer.
  • Webflow — Project Settings → Custom Code → Footer.
  • Next.js / React — load the script in _document / layout with next/script (still use public mdnw_ only).

4. API install — chat, Claude agent, voice-turn

Best for: your app, CRM custom code, mobile backend, or any server that can HTTPS POST.

Base URL:

https://meridian-production-2eb0.up.railway.app

All secret calls use:

Authorization: Bearer mdn_YOUR_SECRET_KEY
Content-Type: application/json

4.1 Chat (simple)

General Q&A. Claude-powered when Meridian has Anthropic configured (production default).

curl -s -X POST "https://meridian-production-2eb0.up.railway.app/api/v1/agents/AGENT_ID/chat" \
  -H "Authorization: Bearer mdn_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d "{\"message\":\"What are your hours?\",\"history\":[]}"

4.2 Claude Agent API (recommended for apps)

Richer response: model, usage, source. Same brain as chat/voice.

curl -s -X POST "https://meridian-production-2eb0.up.railway.app/api/v1/agents/AGENT_ID/agent" \
  -H "Authorization: Bearer mdn_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d "{
    \"message\": \"I need a quote for a furnace install next week\",
    \"history\": [
      {\"role\": \"user\", \"content\": \"Hi\"},
      {\"role\": \"assistant\", \"content\": \"Hello — how can I help?\"}
    ]
  }"

Alias: POST .../claude (same body).

Response fields to use:

  • reply — show this to the user / speak it
  • source — llm (Claude) or fallback
  • model / usage — optional logging

4.3 Voice-turn (phone & voice UIs)

Send the caller’s transcript each turn. Meridian returns what to say next.

curl -s -X POST "https://meridian-production-2eb0.up.railway.app/api/v1/agents/AGENT_ID/voice-turn" \
  -H "Authorization: Bearer mdn_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d "{\"message\":\"I'd like to book Thursday afternoon\",\"audio\":false}"
  • Always speak / display reply (also in platform.say).
  • "audio": true requests Meridian-hosted premium TTS (pay-as-you-go balance required). Most phone platforms leave this false and use Retell/Vapi native voice.

4.4 Node.js example

const BASE = "https://meridian-production-2eb0.up.railway.app";
const AGENT = process.env.MERIDIAN_AGENT_ID;
const KEY = process.env.MERIDIAN_API_KEY; // mdn_…

async function askMeridian(message, history = []) {
  const res = await fetch(`${BASE}/api/v1/agents/${AGENT}/agent`, {
    method: "POST",
    headers: {
      Authorization: `Bearer ${KEY}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({ message, history }),
  });
  if (!res.ok) throw new Error(`Meridian ${res.status}: ${await res.text()}`);
  const data = await res.json();
  return data.reply;
}

// Usage
const reply = await askMeridian("Do you offer emergency service?");
console.log(reply);

4.5 Python example

import os, requests

BASE = "https://meridian-production-2eb0.up.railway.app"
AGENT = os.environ["MERIDIAN_AGENT_ID"]
KEY = os.environ["MERIDIAN_API_KEY"]

def ask_meridian(message, history=None):
    r = requests.post(
        f"{BASE}/api/v1/agents/{AGENT}/agent",
        headers={"Authorization": f"Bearer {KEY}", "Content-Type": "application/json"},
        json={"message": message, "history": history or []},
        timeout=20,
    )
    r.raise_for_status()
    return r.json()["reply"]

print(ask_meridian("What are your hours?"))

5. Webhooks — seamless CRM & automation

Two directions. You only need one of them to start.

A) Your system → Meridian (inbound events)

Send call ends, form fills, CRM stage changes, etc. Meridian logs and can fan out.

curl -s -X POST "https://meridian-production-2eb0.up.railway.app/api/v1/agents/AGENT_ID/events" \
  -H "Authorization: Bearer mdn_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d "{
    \"type\": \"lead.created\",
    \"payload\": {
      \"name\": \"Jane Doe\",
      \"phone\": \"+1-555-0100\",
      \"source\": \"website-form\",
      \"notes\": \"Wants estimate this week\"
    }
  }"

Suggested type values: call.started, call.ended, lead.created, booking.requested, sms.inbound, custom.

B) Meridian → your system (outbound)

Meridian can POST events to your HTTPS URL (CRM, n8n, Make, Slack bridge).

Setup
  1. Create a public HTTPS endpoint that accepts JSON POST.
  2. Send Meridian ops your URL (or set it during DFY install): e.g. https://hooks.yourcrm.com/meridian.
  3. Optional: share a shared secret for X-Meridian-Signature (HMAC-SHA256 of body).

Example payload shape:

{
  "event": "agent.claude_turn",
  "ts": "2026-07-20T12:00:00.000Z",
  "source": "meridian",
  "agentId": "agent_…",
  "businessName": "Acme HVAC",
  "message": "What are your hours?",
  "reply": "We're open Mon–Fri 8–5…"
}

Respond 2xx quickly. Retry logic is best-effort — design your receiver to be idempotent.

6. Phone — Retell, Vapi, or Bland

Meridian is the brain. The phone platform owns the number, STT, and voice. Seamless pattern:

Caller speaks→ Platform STT→ POST Meridian voice-turn→ Speak reply

Steps (any platform)

  1. From your connect guide, download Retell or Vapi config JSON.
  2. Create an assistant; paste the system prompt from the file.
  3. Add a custom tool / server / function:
    • URL: your voice-turn endpoint
    • Header: Authorization: Bearer mdn_…
    • Body: {"message":"{{user_transcript}}"}
    • Speak field: reply
  4. Attach a phone number (or forward your business line).
  5. Place a real test call. Ask hours, booking, price.
Seamless tip

Keep audio: false on voice-turn for phone. Let Retell/Vapi use their native voice (lowest latency). Use Meridian premium TTS only when you deliberately host audio in your own app.

Sales agents use the same API with sales expertise baked in (Claude).

  • Website form → webhook to your server → POST /agent with lead message → send reply via SMS/email.
  • Instant follow-up: on new lead, first message within 60 seconds via your SMS provider (Twilio, etc.) using Meridian’s reply text.
  • Widget: put the chat bubble on landing pages that collect leads.
  • Events: POST lead.created so Meridian (and your outbound webhook) stay in sync.
// Pseudo: form webhook handler

8. n8n / Zapier / Make — copy this recipe

Recipe: “When form submitted → Meridian reply → SMS”

  1. Trigger: Webhook / Form / CRM “new lead”.
  2. HTTP Request (POST):
    • URL: …/api/v1/agents/AGENT_ID/agent
    • Auth header: Bearer mdn_…
    • JSON body: {"message": "…lead context…"}
  3. Parse reply from JSON.
  4. Action: Twilio SMS / Gmail / Slack with that text.
  5. Optional: second HTTP POST to …/events with type: "lead.created".
Zapier mapping

Action: Webhooks by Zapier → Custom Request. Method POST. Data pass-through raw JSON. Next step uses reply field.
