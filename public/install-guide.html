Choose your connection path

Managed phone service

Twilio routes an approved number to xAI Grok Voice. Meridian holds business instructions, tools and safety controls on Railway. Use the phone connection guide. Carrier routing remains an operator task until verified.

Website chat

Copy the widget snippet from your personal guide. Only the public mdnw_ widget token belongs on a website. Confirm answers match approved business facts before publishing it.

Calendar and CRM automation

Use signed HTTPS adapters. The n8n calendar bridge is an inactive template, not a connected calendar. Configure credentials, test failure handling and require confirmed results before activation.

For your developer

Use the actual agent ID and private key from your delivery guide. Call Meridian from your server, not public browser JavaScript.

Base URL: https://meridian-production-4996.up.railway.app
POST /api/v1/agents/:id/agent
Authorization: Bearer <private Meridian API key>
Content-Type: application/json

{"message":"What are your business hours?","history":[]}

Display the reply field. The current text provider is xAI; legacy API aliases do not change the selected provider. For events, use POST /api/v1/agents/:id/events. An event receipt alone does not prove a calendar booking happened.

Phone integration details

Register the approved E.164 number with xAI and configure the signed incoming-call webhook on Railway. Twilio SIP origination uses sip:{number}@sip.voice.x.ai;transport=tls. Keep API keys and signing secrets in runtime secret storage. Never attach an unverified customer number.

Understand your usage

All plan prices are CAD. See the current plans for included minutes and SMS segments. Usage alerts occur at 80% and 100%.

With approved pay-as-you-go billing and a valid card, metered overage is CA$0.45 per AI minute and CA$0.07 per SMS segment. Without it, the plan cap applies. There is a 20-minute wrap-up reminder and a 60-minute safety ceiling. A failed base payment prevents new AI calls; calls already in progress can finish.

If something does not work

No private setup link?

The public wizard is a preview. Do not create a fake agent ID or reuse someone else’s credentials. Return to your proposal or provisioning message and request the correct private link.

Sample audio works but the phone does not?

A recorded website sample is separate from phone routing. Check the connection hub and ask Meridian to verify the assigned number and call ledger. Do not change provider credentials in your browser.

A booking was mentioned but there is no event?

Stop launch. Verify the calendar adapter and actual event before treating the booking as confirmed. Record the failure and retest create, reschedule and cancel.

AI chat is unavailable?

The setup checklist and connection checks remain available. Open Setup help in the AI guide for direct links without sending a message.
