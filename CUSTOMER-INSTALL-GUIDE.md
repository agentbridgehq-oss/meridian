## Seamless experience (what the customer feels)

1. Pay or finish Meridian AI chat setup  
2. Open personal connect guide: `/guide/<token>`  
3. Pick one path: **widget** (fastest) · **API** · **webhooks** · **phone**  
4. Copy-paste · test · go live  

Secret key (`mdn_`) stays on servers. Widget uses public `mdnw_` only.

---

## Paths

| Path | Time | Best for |

| API (`/agent`, `/chat`, `/voice-turn`) | ~15 min | Apps, CRM backends |
| Webhooks inbound/outbound | ~20 min | n8n, Zapier, Make, CRM |
| Phone Retell/Vapi | ~30 min | Real phone number |
